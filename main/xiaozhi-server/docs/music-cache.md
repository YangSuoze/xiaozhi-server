# 在线音乐缓存

在线歌曲统一写入 `data/music_cache`，项目的 `music` 目录不再接收运行时下载文件。

缓存默认规则：

- 总容量不超过 256 MB；
- 最多保留 30 首；
- 单个文件不超过 50 MB；
- 24 小时没有使用的文件会过期；
- 已经交给播放线程的文件保护一小时；
- 下载失败或进程中断留下的临时文件会自动清理。

每次下载都先写唯一的 `.part` 文件，并在内容完整且大小合法后原子替换为正式文件。相同歌曲的并发请求共用一份下载，文件名使用歌曲 ID 的哈希，不使用外部返回的歌名或歌手名。

清理会在缓存访问和下载提交时执行。提交新文件之前先按最近使用时间删除旧文件；如果容量全部被正在播放的文件占用，本次下载会失败，不会突破硬容量上限。

这些限制可以在 `config.yaml` 的 `plugins.play_music` 中调整。私有环境需要不同参数时，在 `data/.config.yaml` 中只覆盖对应字段。

旧版本下载到 `music` 目录的文件不会自动删除，因为该目录也可能包含人工放入的歌曲。升级部署后应先确认内容，再手动清理旧下载；新代码不会继续向该目录写文件。
