# 本地可靠性修复说明

本次修改只在本地副本完成，没有同步或重启阿里云服务。

## 已修复

- WebSocket 默认开启鉴权；OTA 只有在设备 ID 和设备预置密钥都匹配时才签发连接令牌。
- 日志隐藏 Authorization、密码和设备密钥。
- 同步意图模型移入受限工作线程，并增加 15 秒超时。
- 意图缓存包含最近对话、工具列表和当前分钟；时间与时区每轮重新注入。
- 闹钟采用到期比较，不再要求程序恰好运行在目标秒。
- 一次性闹钟离线时保持待投递，设备重新连接后重试；超过 24 小时才过期。
- 重复闹钟允许 5 分钟补发，之后跳到下一个有效周期。
- 闹钟文件使用原子替换；保存失败不会回复设置或删除成功。
- 查看和删除闹钟按设备隔离。
- 旧连接只清理自己的登记，不会删除同一设备的新连接。
- 服务端不再向不支持该协议的固件发送 set_timer 假指令。

## 鉴权上线顺序

当前云端地址仍是 HTTP/WS。设备密钥和语音数据必须改用 HTTPS/WSS 后再上线鉴权。

1. 在阿里云反向代理上配置可信 HTTPS/WSS 域名，后端端口继续只供本机代理访问。
2. 把固件的 OTA 地址改成 HTTPS，把服务器下发的 WebSocket 地址改成 WSS。
3. 保留本地私有密钥文件，重新编译并刷入固件。设备密钥文件已被 Git 忽略。
4. 部署服务器代码和私有配置，再验证 OTA 返回令牌、音箱连接及语音问答。

不要直接把当前启用鉴权的本地配置覆盖到云端；旧固件没有预置密钥，会立即无法连接。
编译出的固件包含设备密钥，不要公开上传或分享该二进制文件。
